# Burrquizzz – Design Philosophy

## O que é

Burrquizzz não é um dashboard.

Burrquizzz é um game show de curiosidades.

A sensação deve ser parecida com participar de um programa de TV.

## Personalidade

Divertido.
Inteligente.
Levemente caótico.
Cheio de descobertas.
Nunca infantil.

## Objetivo visual

O usuário deve sentir que:

- começou uma aventura;
- cada pergunta é um pequeno evento;
- descobrir algo novo é recompensador;
- acertar é divertido;
- perder não é frustrante.

## Princípios

- Um protagonista visual por tela.
- Pouca profundidade.
- Evitar card dentro de card.
- Sombras discretas.
- Cores fortes apenas quando têm significado.
- Animações rápidas.
- Informação secundária sempre discreta.

## Nunca fazer

- aparência de dashboard corporativo;
- excesso de containers;
- excesso de glow;
- excesso de bordas;
- excesso de caixas.

## Meta

Parecer um jogo produzido por um pequeno estúdio independente.
